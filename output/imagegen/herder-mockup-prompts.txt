workspace-groups

Use case: ui-mockup.
Asset type: high-fidelity mobile web terminal concept comparison board.
Create a crisp landscape 1600x1100 raster UI mockup board with exactly TWO large straight-on portrait app screenshots side by side, each with mobile viewport proportions 390x844, no perspective, no physical phone hardware, no OS status bars or browser address bars. Put a concise title above both screens, concise state captions above each screen, and a small right arrow between them. Screens must be large, clean, and legible, nearly filling the height. Practical flat UI, sharp type and restrained borders; no decorative illustrations, gradient glows, marketing copy or watermarks.
